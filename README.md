# HistoricalConflictZone
Data exploration and visualization of the conflict zones, 1946 - 2025

# Citation
UCDP requires citation of the dataset, and the version number must appear in any analysis. If you publish anything built on this pipeline, cite:

Gleditsch, N.P., Wallensteen, P., Eriksson, M., Sollenberg, M., & Strand, H. (2002). Armed Conflict 1946–2001: A New Dataset. Journal of Peace Research 39(5): 615–637.

Davies, S., Pettersson, T., & Öberg, M. (2026). Organized violence 1989–2025, and violent political protests. Journal of Peace Research 63(4).

Pettersson, T. (2026). UCDP/PRIO Armed Conflict Dataset Codebook v26.1. https://ucdp.uu.se/downloads/

The pipeline carries version through to a metadata sidecar in every output directory so the release is never lost in transit.
